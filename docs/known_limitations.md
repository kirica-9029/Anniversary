# Anniversary Keeper Windows v1.0 既知の制限

文書更新日：2026年10月13日。

- 対象はWindowsです。他OSでの公開・動作保証はありません。
- アプリ独自のアカウント・cloud同期・backendはありません。OSや同期ソフトによるDocuments同期は別の仕組みです。
- 商品情報・画像・価格、Wishlist内容を自動取得しません。URLは明示的に開いたときだけ既定ブラウザへ渡します。
- 郵送先等の秘匿Destination、配送追跡、為替換算、Groupへの直接Recipient指定は未対応です。
- Windows通知の表示はOS設定や端末状態に影響されます。通知クリックから対象イベントへ直接移動する機能はありません。通常の通知にはイベント名が含まれ、本文の一部は英語です。アプリ内の通知内容を非表示にする切替画面は提供していません。
- 新規backup保存先と通常Restore選択先はDocuments直下の.akbackupです。他folderを直接指定できません。backup password紛失時の復号・復旧を保証できません。
- Restoreは現在のデータをbackup時点へ置き換えます。差分追加やマージではありません。未対応の形式・schemaや不整合なbackupは拒否します。
- 既存の未暗号化DBを通常起動時に無条件で自動移行しません。DBや資格情報に不整合がある場合、データをresetせず起動を拒否する場合があります。
- 暗号化はログオン中の同一ユーザー権限で動く不正ソフトウェア等からの完全な防御ではありません。
- 完全削除はsecure eraseではありません。過去backupからデータが再出現する場合があります。自動VACUUM・自動期限削除はありません。
- アンインストール後もDocuments DB・外部backup等は残ります。DBと資格情報の片方だけを手動削除すると、再起動・再インストール後に安全のため起動を拒否する場合があります。
